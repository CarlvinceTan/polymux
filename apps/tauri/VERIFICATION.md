# Tauri verification

The Swift app has been removed; the Tauri app is now the only client. The historical Swift comparisons below establish the layout baseline, but a passing build or browser test does not establish native visual or behavioral parity. Check each surface in the isolated app with real data, failures, keyboard access, narrow and wide windows, and light and dark appearance where relevant.

The outbox retains queued messages and attachment bytes across reloads and lets the user delete unsent messages. Replay checks the server's reported host and device IDs, which detects ordinary replacement but does not authenticate the server. Messages queued without a known identity remain held. Lost upload acknowledgments can leave orphaned uploads, and a suspended window can outlive its delivery lease.

Chat streams replay contiguous events before reconnecting and commit the cursor, messages, and runs in one cache transaction. Gap repair, delta-only replay, and interrupted cache transactions have browser coverage. Replay is buffered in memory until caught up, and different windows can still race when they save different state at the same cursor. Acknowledged choice and reaction overlays remain in memory until replay completes; the server does not supply an acknowledgment sequence to order concurrent clients unambiguously. An accepted outbox entry can remain locally queued if its chat is closed before replay finishes, until that chat is reopened.

The macOS dictation bridge uses SFSpeechRecognizer and has mocked lifecycle, draft, and composer coverage. Real microphone permission, audio capture, recognition, and native waveform behavior have not been tested. Swift's primary SpeechAnalyzer, local-recognition failure replay, and dictation polish are not yet ported; other platforms report dictation unavailable.

The media cache follows Swift's 200 MiB eviction policy, keeping the newest download even if it exceeds the limit. This conflicts with DESIGN.md's requirement that everything previously loaded stay viewable offline; storage quota can also prevent persistence.

The Unslop audit of a populated chat and profile found restrained neutral surfaces, with small metadata, mixed text glyphs and icons, repeated capsule treatments, and a theme-independent profile-tab hover color to review during the redesign. Its proposed direction is a focused, conversational workbench: agent silhouettes and real message content carry the visual detail. ## Security gap

The native HTTP plugin currently permits arbitrary HTTP and HTTPS destinations and exposes its `unsafe-headers` feature to the renderer. Native server requests suppress `Origin` to match Swift and pass the server's native-only checks, but the renderer can also invoke the plugin directly and control forbidden headers. Automatic owner-token discovery is limited to local hosts and addresses as in Swift, but the owner token is still exposed to renderer code and paired tokens are stored in local storage. The production content security policy restricts script and resource loading, but injected renderer code could still misuse those capabilities. Move credentials and server-route enforcement into native code before release.
