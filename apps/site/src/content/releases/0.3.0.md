## Features

### Desktop

- Connect account-linked devices and choose where Assistant work runs.
- Store passwords, authenticator codes, recovery codes, and passkeys in an encrypted Locker.
- Organize chats into folders, duplicate conversations, and fork from a selected response.

### AI

- Use external agent runtimes with workspace tools and Team collaboration.
- Create a Team bot that introduces itself and begins the work its role describes.
- Edit and resend an earlier message to continue from the revised conversation.

### CLI

- Run shell commands from the terminal chat, remember their working directory, and choose whether their output joins the next prompt.

### Phone

- Connect to a desktop Host and access Locker from the phone app.
- Control supported Android and iPhone devices from the workspace.

### Browser

- Use Locker passwords and passkeys through the browser extension.

### Hub

- Preview photos and videos in conversations, open them in Media, and save attachments.

### Site

- Share a read-only conversation snapshot with a link that expires after 24 hours.

## Bug Fixes

### AI

- Keep cancelled external-agent responses out of subsequent runs and reset their context when a conversation is rewound.
- Preserve encoded characters in saved reference links.

### Desktop

- Keep sign-out available offline and separate device pairing across accounts.
- Keep revealed Locker secrets associated with the selected item.
- Recognize the correct app instance during background automation when several copies are running.

### Hub

- Show WeChat photos, stickers, and call durations with the correct sender alignment.

### Phone

- Preserve authenticator and passkey secrets when editing Locker entries.
- Keep AutoFill usable after an authenticator cannot generate a code.

## Improvements

### Desktop

- Browse usage separately for Assistant and Team, with totals for the runtime agents used in each.
- Find a message from search and jump straight to it in the conversation.
- Keep editor focus and unsaved changes while typing, and recognize more file formats.
- Publish cloud vault updates only after their encrypted contents are stored successfully.

### CLI

- Show clearer working states, rounded tool cards, and a smoother generation-speed display.

### Browser

- Authenticate extension access to desktop Locker and keep master-password entry in trusted app surfaces.

### Hub

- Reduce repeated database work while WeChat is idle.

### Site

- Keep public conversation pages isolated from local desktop actions.
