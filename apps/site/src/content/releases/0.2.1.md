## Features

### AI

- Work with provider-neutral agent conversations, local memory, tools, skills, MCP connections, and focused Subagents.

### Workspace

- Move between Hub, Drive, Browser, Tasks, and schedules without leaving the main conversation.

### Hub

- Bring email and connected messaging services into one communication workspace.

### Drive

- Work with local files and supported cloud storage through a unified virtual drive.

### Desktop

- Install the first public preview on macOS, Windows, or Linux.

## Improvements

### Desktop

- Choose a streamlined basic setup or expose additional provider and agent controls with Advanced mode.
