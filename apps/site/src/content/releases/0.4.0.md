## Features

### Desktop

- Chat with your agents in a native macOS app, with searchable conversations, attachments, replies, reactions, and group chats.
- Give each agent its own profile, instructions, tools, and animated avatar.
- Enter and reveal credentials through private vault cards rather than putting secret values in chat.

### CLI

- Run the agent server separately from the app, so agents can keep working while clients are closed.
- Pair other Macs with one-time invitation links and manage linked devices from Settings.

### AI

- Configure model providers and select the models your agents use from Settings.
- Give agents persistent memory, scheduled work, skills, and MCP connections.

## Improvements

### Desktop

- Release builds check for signed Mac updates through Sparkle.
- The native client requires macOS 27 and a separately installed Polymux server. This is a different app from the retired Electron releases; it does not migrate their workspace automatically.
- iPhone distribution through TestFlight is not included in this Mac release.

### Site

- Updated installation and configuration guides for the native app and server.
- Archived the Electron releases and retired their installers and update feeds.
