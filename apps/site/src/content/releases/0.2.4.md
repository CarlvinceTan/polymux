## Features

### Hub

- Link the same person across messaging services and keep each connected conversation available from one contact.
- Use the implemented WeChat bridge paths for verified text, media, files, voice messages, replies, mentions, read state, and recall.

### Desktop

- View and edit calendar events from the workspace using the native macOS calendar connection.
- Use packaged voice dictation helpers across supported desktop platforms.

## Improvements

### Browser

- Browser extension compatibility is checked before releases, while incompatible requests stay isolated from valid control sessions.

### Desktop

- Release packages verify their messaging bridges, native helpers, speech runtime, and WeChat writer before publication.

### Site

- Download and release routes now fail safely when GitHub is unavailable and reject unpublished version probes without spending API quota.
