# References

Products Polymux compares itself against. They guide behaviour, not UI parity, and every idea taken from them must still pass `architecture.md`.

- **Grok Bot**: [b-nnett/grok-bot-0.18-reconstructed](https://github.com/b-nnett/grok-bot-0.18-reconstructed), a reconstruction of the shipped 0.18 macOS app. Its mobile app also connects to phone data (calendar, reminders, contacts, location, Home).
- **Rakazo**: [elie222/rakazo](https://github.com/elie222/rakazo), an open-source Grok Bot alternative.
- **OpenBot**: [CopilotKit/OpenBot](https://github.com/CopilotKit/OpenBot), self-hosted "AI coworkers". Not to be confused with [ashhart/OpenBot](https://github.com/ashhart/OpenBot), a separate, small Grok Bot reimplementation.
